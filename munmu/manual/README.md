# 문무: 하나의 깃발 · 게임 매뉴얼

이 디렉터리는 제공된 대화 대본과 아트 패키지를 참조하는 **로컬 기획 초안**이다. 플레이 가능한 게임, 검증된 역사 백과, 완성된 제작 명세가 아니다. 각 판의 원문과 시험 제안을 구분한다. 최신 요청에 따라 영웅은 누구나 이동 가능하며 2D 전장·3D 인물·엔진 미정을 기준으로 한다.

## 실행

프로젝트 루트에서:

```sh
python3 -m http.server 4192 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4192/munmu/manual/`을 연다. ES 모듈 및 스테이지 데이터와 기존 아트 참조 때문에 HTML 파일을 직접 여는 방식은 지원하지 않는다.

## 2026-11-04 통합 제작 매뉴얼

`production.html`에서 확정된 디자인 방향, 영웅·병종·전장 목록과 Meshy 동작 및 무기 결합 검증 계획을 함께 본다. `production.js`는 기존 `redesign-data.js`와 `stages.json`을 참조한다. 기존 시안과 자료는 보존한다. 실제 모델·무기·애니메이션은 아직 만들지 않았다.

## 구성과 미완료

- `build-data.py`: 제공 대본의 36개 이야기와 전후·중 대사를 `stages.json`으로 추출. 대본 원문은 수정하지 않는다.
- `stage-designs.js`: 각 판의 목표·구역·성공 조건에 대한 시험 제안. 역사적 사실이나 최종 규칙이 아니다.
- `app.js`: 영웅, 공용 기술, 병종, 탐색 화면. 공통 웨이브는 대본 사건을 포함한 자리표시 초안이다.
- `assets/`: 생성한 기준 이미지 초안. 리깅 적합성·역사·배우 유사성 검수 전이며 완성 3D 모델이 아니다.
- 맵 전부의 개별 배경, 다수의 영웅·병종·보스 모델 입력 이미지, 배우별 자료, 세부 밸런스·보상·웨이브와 실제 전투 검증은 미완료다.

대본을 다시 추출할 때는 프로젝트 루트에서 `python3 munmu/manual/build-data.py`를 실행한다. `stage-designs.js`의 수동 제안은 덮어쓰지 않는다. Meshy 생성이나 엔진 선택은 진행하지 않았다.

## 삼국 분기와 진영 표식 · 2026-11-04

- 현재 사용자 지정 게임 기준: 신라 백색·천마, 고구려 청색·청룡, 백제 황색·봉황, 당 적색·주작. 이는 게임의 식별 체계이며 역사적 국가 군복·국장이라는 의미는 아니다.
- `production.html#faction-identity`: 새로운 진영별 장수·병사 비교 시안 4종. 종전 영웅 13종·병사 24종은 이전 색상 기준이며 교체 전이다.
- `campaign-branches.html`: 신라·백제·고구려 경로의 핵심 전투·대진·목표와 IF 분기 제안, 신라 원본 대본 36개 전투의 상대 진영 인덱스. `campaign-branches.js`는 경로의 제안 데이터다.
- 백제·고구려 루트는 설계 제안이며 플레이 가능한 캠페인이나 완성 대본이 아니다. 각 전투의 역사성, 상세 웨이브·보상과 분기 이후 인물 관계는 재검토한다.
