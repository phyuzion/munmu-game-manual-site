# 영웅·병사 진영 재설계 v006

상태: 생성 시안, 고증·배우 유사성·모델 입력 검수 전. 공통 화풍은 스타일리시 카툰 로우폴리, 삼국 갑옷 구조와 시대별 출처는 ARMOR_SOURCE_RESEARCH.md를 따른다. 새로운 동물 문장은 **역사적으로 실증된 개인·국가 문장이라고 주장하지 않는 게임용 창작**이다.

## 공통 기준

- 영웅: 전면과 후면에 알아보기 쉬운 개인 문장 1개를 배치하고 얼굴, 머리와 장비로 개성을 준다. 장식의 크기가 갑옷의 재질과 연결을 가리지 않는지, 전면과 후면에 같은 문양이 재현되었는지 개별 확인한다.
- 병사: 해상도를 낮추거나 이미지에 흐림 효과를 주지 않는다. 눈·코·입의 형태와 대비, 표현량을 줄인 단순한 얼굴로 영웅과 구분한다. 전면과 후면이 이어지는 동일 인물 시안이다.
- 투구: 진영의 색과 갑옷 구성은 통일하되 각 영웅의 둥근 투구, 목가리개, 능선, 깃과 맨머리 등 실루엣을 다르게 제안한다. 사방으로 넓은 삿갓형은 사용하지 않는다. 형태는 유물 비교와 별도 검수가 필요하다.
- 신라 남청·밝은 선과 철제 연결판, 백제 적갈·칠피 가죽의 재질, 고구려 먹빛 찰갑·진홍 선은 나라 식별을 위한 시안이다. 실제 군복 색이나 국가의 독점 양식을 증명하는 표기가 아니다. 당군은 황토·갈색 제안이다.
- 당나라 갑옷을 입는 김인문은 인물의 소속과 착장 진영을 구분한다. 상영과 고연무는 적·아군에서 동일한 인물의 장비를 유지한다. 시득은 맨발, 설오유는 흉터와 낡은 갑옷, 김유신은 흰 수염을 원본 자료에 맞춰 확인한다.
- 나란히 그린 앞·뒤는 제작 검토용 컨셉 이미지다. Meshy에 바로 넣을 분리된 단일 캐릭터 정면 이미지, 뒷면 정합성, 토폴로지·리깅·재질, 배우 유사성은 별도 검수 대상이다. 말과 무기 역시 별도 자산이다.
