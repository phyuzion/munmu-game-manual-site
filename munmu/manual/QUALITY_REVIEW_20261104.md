# 문무 시나리오·에셋 검수 기록

## 이번 작업의 실제 범위
- 기존 신라 36전투 대본과 기획은 보존했다. 백제·고구려 각각 36전투에 창작 구역과 대사 초안을 추가하고, 기존 IF 12전투의 대사·웨이브·목표를 대응시켰다.
- 백제·고구려 72전투의 웨이브 표·보상·출전·지휘관 능력치는 시험용 제안이다. 기존 IF 12개를 제외한 구성은 공통 병종 편성 규칙을 활용했으며, 판별 밸런스 및 사료 대조가 끝난 상세 설계가 아니다. 장면의 대사는 대본 초안이지 완성 대본이 아니다.
- 108전투의 넓은 배경 후보 이미지가 존재한다. 일괄 생성된 이미지는 대체로 같은 전장처럼 보이며 불필요한 강, 좁은 성문, 다른 진영 깃발이 나타난다. 파일 수로 품질을 합격 처리할 수 없다. 이미지별 지형, 시대, 출입구 폭, 점령 구역, 시점, 진영 문장 검수가 남아 있다.
- 신라 1-1/백제 1-3 대야성과 고구려 6-4 평양은 서로 겹치는 지형을 새로 그려 연결했다. 백제 4-1/신라 4-1 황산벌은 성곽 없는 열린 들판 후보를 연결했다. 신라·고구려 5-2의 얼음 나루와 신라 9-4 기벌포의 넓은 수로 후보도 별도 생성해 연결했다. 이 후보들도 정확한 충돌·오브젝트 분리 및 시대 고증은 미검증이며 기벌포의 당 군기 문양은 재검토가 필요하다.
- 전투별 9칸 폭 구역 배치도는 자동 생성된 설계 초안이다. 고유 출현점·전력 배치·우회로·목표와 실제 게임 충돌 데이터는 아직 작성하지 않았다.
- 24개 영웅 외형, 24개 병사 외형, 추가 적장 15개, 원본 NPC 17개(죽죽은 적장 목록과 공유)에 단독 T포즈 2D 시안이 있다. 연정토의 수정 시안은 얼굴이 다른 카툰 인물보다 사실적으로 보여 화풍 검수가 필요하다. 배우 식별성, 손가락, 털과 어깨의 분리, 다리·치마갑옷 분리, 등면, 정면/측면 형상과 Meshy 결과는 검수 전이다. 고연무의 배우는 백성현이며 연개소문 참고와 분리해 다시 생성했다. 실제 유사성은 확인하지 못했다.
- 진영색은 신라 청색·은백/천마, 고구려 흑색/청룡, 백제 어두운 갑옷·금빛/봉황, 당 적색/주작으로 설정했다. 일부 시안은 작은 갑옷 장식이나 얼굴에 추가 수정이 필요하다.
- 검·화살 및 화살통·충차를 포함해 오브젝트 32종의 이미지 시안을 확보했다. 앞선 생성 요청은 거절됐지만 개별 오브젝트로 다시 생성했다. 모든 이미지는 2D 시안이며 실제 3D 게임용 모델이 아니다. 검의 손잡이, 활시위·화살, 충차의 구조·분리와 역사적 형태는 모델 제작 전에 검수해야 한다.

## 계속 필요한 작업
1. 역사와 창작을 구분하고 72전투의 승리·실패 판정, 출현점·웨이브·대사·적장·보상을 개별적으로 재집필하고 플레이 시험한다.
2. 108전투 배경을 시나리오와 실제 9×16 임시 카메라·모델 크기에 맞춰 전투별로 다시 설계·제작한다. 반복 생성된 후보를 완성 맵으로 취급하지 않는다.
3. 주요 드라마 배역별 실제 참고와 캐릭터 얼굴을 직접 대조하고, 잘못된 문장·색·손·얼굴·장비를 고친다. 배우 미확인 인물은 단정하지 않는다.
4. 실제 모델·무기·망토를 분리한 뒤 Meshy와 엔진에서 리깅·애니메이션·충돌·성능을 시험한다. 2D 시안은 그 결과가 아니다.
