전장 데이터

격자는 지형·오브젝트를 배치하는 기준이다. 영웅과 몹은 칸에 고정되지 않고 연속 좌표로 자유롭게 움직인다.

현재 범위 · 대야성 2개 시점 시험신라 1-1과 백제 1-3은 동일한 8×36 지형을 공유하며 진영·출현점·목표가 다르다. 가로 8칸이며 중앙 다리·성문은 6칸 폭으로 시험한다. 한 칸이 캐릭터 한 명의 폭이라는 뜻은 아니며 유닛 크기·동시 통과 수는 별도 검증한다. 배치와 수치는 기획 시험안이다. 나머지 전투의 격자 데이터는 아직 만들지 않았다. 이미지 시안은 3D 모델이 아니다.
흙길 · 이동 가능숲 · 이동 비용 1.5 / 시야 차단물 · 도보 이동 불가다리 · 6칸 폭P 아군 출현점E 적 출현점A 공격자 · 원의 크기 = 충돌 크기B 대상 몹

맵의 오브젝트는 점유 영역을 보여 주는 도형이며 실제 3D 모델이 아닙니다. 맵을 누른 지점에 A와 B를 차례로 놓습니다. 드래그 모드에서는 원을 칸과 관계없이 끌어 위치를 시험할 수 있습니다. 장애물을 통과하는 이동 물리는 아직 구현하지 않아 잘못 겹친 위치를 경고만 합니다. 두 원은 유닛의 충돌 크기이며, 좌표 입력으로 소수 위치를 조절할 수 있습니다. 클릭 위치도 칸에 맞춰 고정되지 않습니다. 키보드는 맵에 초점을 둔 뒤 방향키와 Enter를 사용합니다. 저장되는 preview 값은 배치 시험 상태이고 실제 게임 내 유닛 배치가 아닙니다. 편집은 현재 브라우저에서만 이뤄지며 JSON 저장을 눌러 파일로 내려받아야 합니다.

칸과 구역

grid 크기와 좌표계, tiles[y][x]의 지형·높이, zones의 구역 범위를 저장한다.

오브젝트와 임무

objects는 기존 오브젝트 ID·칸 점유·이동/시야 차단·문 상태를, spawns와 mission은 출현점·진영·승패 조건·웨이브 사건 제안을 저장한다. 목표와 이벤트의 실제 실행은 아직 구현되지 않았다.
