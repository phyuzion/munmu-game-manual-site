BATTLEFIELD / SCALE STUDY

길이 아닌
부대가 싸울 전장

기존의 풍경형 맵은 경로·성문·다리를 인물에 맞춰 설계하지 않아 전투용 축척을 보장하지 못한다. 아래 그림은 사람을 작게 줄이는 대신, 영웅과 병사의 크기를 먼저 놓고 그에 맞춰 이동 면적을 잡는 시험안이다.

영웅 3명아군 병사적 병사이동 장애물

읽는 법

9×16칸은 실제 화면에 보이는 범위를 시험하기 위한 임시 기준이다. 전체 스테이지의 크기를 9×16으로 제한하지 않는다. 길게 진행하는 판은 여러 화면 높이로 이어지고 선택한 영웅을 따라 카메라가 이동한다.

원 한 개는 개체 한 명의 바닥 점유 공간을 보여주는 자리 표시다. 실제 캐릭터 스프라이트·모델은 위로 더 크게 보이고, 애니메이션 및 무기 휘두르는 범위는 이 원보다 넓다. 캐릭터와 같은 크기의 실제 이미지가 아니며 게임 플레이 검증도 아니다.

주 통로는 화면에서 약 7칸, 최소 시험 폭은 6칸으로 설정했다. 한 줄 6명과 이격을 시각적으로 대조하고, 진형 이동과 양쪽의 교전 여유는 실제 모델·충돌 판정으로 검증한다.

문·여울은 6칸 이상을 시작값으로 삼는다. 좁은 곳이 필요한 전투라도 병목의 폭과 대체 경로·목표를 명시한다.

PRODUCTION RULES / TEST VALUES

전투가 먼저 들어가는 배경

화면과 전체 스테이지

9×16칸은 한 화면의 출발점이다. 공격판은 산 → 강 → 성처럼 구역을 세로로 이어 붙이고, 각 구역에서 전투·배치·후퇴가 가능한 공간을 확보한다. 수성판은 성벽 앞 넓은 교전지와 성벽 궁병 배치대를 구분한다.

화면 비율, 카메라 크기와 이동 속도는 실제 모델을 띄워 조절한다. 격자 수치나 화면 밖 처리 방식은 확정값이 아니다.

맵을 그리는 순서

① 영웅·병사 기준 크기 → ② 부대 진형과 서로의 간격 → ③ 이동 가능 영역과 성문·도강 폭 → ④ 스킬·포위·우회 공간 → ⑤ 지도 배경과 장식.

미술 이미지의 길 윤곽은 충돌 데이터가 아니다. 실제 경로와 장애물은 별도 데이터로 작성하고 게임에서 겹쳐 확인한다.

현재 지도는 시안이다. 6명 동시 통과, 영웅 3명 조작, 성문·여울의 통과, 실제 카메라와 이동 성능은 모델과 실행 화면에서 아직 확인하지 않았다.

NEW CONCEPTS

넓은 전장 이미지 시험

맵 그림은 확대·축소 없는 고정 전투 카메라를 가정한 배경 시안이다. 경로와 크기는 위 배치도에 맞춰 실제 제작 시 다시 검수해야 한다. 생성 전인 그림은 미완성으로 표시한다. 수성 시안의 성문은 여전히 좁아 재작업해야 하고, 공성 시안의 넓은 아치도 폭을 확인하기 위한 임시 형상이라 시대 고증과 별도 문짝 설계가 필요하다.
