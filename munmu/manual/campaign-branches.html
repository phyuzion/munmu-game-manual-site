FOUR FACTIONS · THREE PLAYABLE CAMPAIGNS

같은 전쟁,
서로 다른 깃발

신라의 기존 이야기를 기반으로 백제와 고구려의 선택 가능한 독립 캠페인을 더한다. 각자의 대의와 적, 공성·수성 목표가 달라지고 가상의 승리 이후에는 백제 또는 고구려 주도의 통일까지 이어진다.

당 · 적색 · 주작

시기와 경로에 따라 동맹 또는 적. 플레이 진영 여부는 미정.

사용자 확정과 기획 제안

네 진영의 색·상징, 백제·고구려로 진행하고 통일할 수 있다는 방향은 확정. 아래 스테이지 구조·해금·등급·IF 사건은 제안이다. 진영의 색과 상징은 게임의 시각 체계이며 역사적으로 군복과 국장을 확정했다는 의미는 아니다.

독립 저장 · 세계선

신라·백제·고구려 경로를 선택하고 각자 진행 상태와 전장 결과를 저장한다. 같은 전장의 승패가 다른 경로에 소급 적용되지 않는다.

동맹은 장면과 시기에 종속

신라와 당은 처음부터 끝까지 같은 편이 아니다. 역할은 스테이지별로 지정하며 실제 역사와 IF의 분기점을 화면에 명시한다.

ROUTE MAP / PROPOSAL

시나리오 분기와 대진표

각 경로의 6개 항목은 전체 흐름을 보여주는 주요 분기·전투 묶음이다. 전체 판 수가 6개라는 의미가 아니다. 신라는 기존 36개 대본을 보존하며, 백제·고구려는 아래 가상 전장과 중간 스테이지·대사를 추가 집필해야 한다.

ORIGINAL SCRIPT / MATCHUPS

기존 신라 36전투의 대진

제공 대본의 적장과 전투 제목을 기준으로 정리한 게임 내 진영 대진이다. 역사적 소속·연도 및 대본의 실제 병력 편성은 재검토 중이며, 확인되지 않은 항목은 그렇게 표시한다. 여러 세력의 동맹·귀순이 등장하는 판은 상세 대본이 필요하다.

HERO RARITY AND ALLEGIANCE

등급은 영웅의 성장과 선택을 위한 제안

C → B → A → S → SR. 현재 등급은 테스트용이며 등급이 곧 국가 계급이나 무조건적인 승리를 뜻하지 않는다. 진영·출신, 현재 충성, 착장, 전장 역할과 플레이어블 여부를 별도로 기록한다. 각 영웅의 기술은 기존 기준대로 2개다.

당김인문은 신라 인물이지만 대본상 당군 착장당 장수의 역할과 이미지·등급 검토신라 경로 후반·IF 경로에서 적으로 출현 가능

기존 인물별 문장과 새 진영 상징은 분리한다. 진영 공통 문장과 영웅별 개인 문장을 가슴·등·군기·방패·소매에 어떻게 함께 배치할지는 추가 디자인 안이다. 위치·크기는 시안 검수 후 확정한다. 소속 변경이 일어나는 인물의 착장과 진영 표시는 별도로 설정한다.

실제 사건과 가상 결말의 경계

신라와 당의 동맹 및 이후 대립, 660년 백제와 668년 고구려의 멸망은 역사 자료로 대조한다. 백제나 고구려의 방어 성공과 각 나라 주도의 통일은 게임용 IF다. 역사적 전투를 다른 시점으로 재구성한 플레이도 실제로 그 결과가 있었다는 뜻이 아니다.
